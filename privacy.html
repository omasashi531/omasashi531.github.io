LAST LIFE LOG 制作ツール「last-life-log」

このアプリについて

このアプリは、LAST LIFE LOG の運営者本人が、自分のYouTube動画を作るためだけに使う制作ツールです。運営者以外の人が使うことはありません。

使うデータ

  • Googleドライブのうち、運営者が指定したフォルダから、曲・画像・設定ファイルを読み取ります（drive.readonly）。
  • 作った動画・サムネイル・文章は、このアプリが作ったGoogleドライブのフォルダに保存します（drive.file）。

データの扱い

  • 読み取ったデータは、動画を作るためだけに使います。
  • 第三者に渡したり、販売したり、広告に使ったりすることはありません。
  • 処理に使った一時ファイルは、作業が終わると削除されます。
  • Google API から受け取ったデータの使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

お問い合わせ

YouTubeチャンネル（@lastlifelog）からご連絡ください。

Privacy Policy (English)

This app ("last-life-log") is a production tool used only by the owner of LAST LIFE LOG to create their own YouTube videos.

  • It reads songs, images and settings files from a Google Drive folder chosen by the owner (drive.readonly).
  • It saves the resulting videos, thumbnails and text to a Google Drive folder created by the app (drive.file).
  • Data is used only to produce videos. It is never shared with or sold to third parties, or used for advertising.
  • Temporary files are deleted after processing.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact: via the YouTube channel (@lastlifelog).
